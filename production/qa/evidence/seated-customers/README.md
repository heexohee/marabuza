# 착석 표현 반영 검증

2026-09-28. 기본형 basic.png, 업그레이드 5단계 upgraded.png.

실제 게임 render와 CSS에 테스트 상태(4개 좌석, 토끼/고양이/판다/빈자리)를 넣어 브라우저에서 캡처했다. 사용자 저장 데이터를 사용하거나 수정하지 않았다. 정면 의자, 상판, 앞발, 종별 털색 몸통과 공통 크림색 턱받이, 빈 좌석, 주문 번호와 인내심 막대 간격을 육안 확인했다. 수정 시안 기반 PNG 가구를 사용한다. 몸통 높이는 13→10 native px, 얼굴은 28→32px(토끼 40px)로 조정했다. 의자는 몸 바로 뒤에 배치했다. 가구 업그레이드는 가구 이미지와 색상만 변경한다.

관련 테스트: animal_faces_test, shop_stage_test, price_table_test, flow_test — 36개 통과. 실제 좌석 상한은 기존부터 4개였으며, 이전 QA fixture에만 잘못 5개를 배치했던 것을 수정했다. 선결제 착석, 서빙, 잘못된 좌석, 환불 및 퇴장 등 기존 흐름 검증. 현재 게임은 서빙 즉시 퇴장하므로 대기 좌석에 음식 그릇을 미리 표시하지 않는다. 식사 애니메이션은 추가하지 않았다.

로컬 임시 QA 페이지는 검증 후 제거했으며 릴리스에는 포함하지 않는다.

추가 수정: 의자 스프라이트의 아래 60%를 CSS로 가려 좌판/다리를 숨겼다. 등받이는 8px 높였다. 얼굴 하단 투명 여백을 고려해 턱을 몸통과 겹치게 내리고, 귀/두건으로 비대칭인 토끼와 판다는 얼굴 하단 중심 기준으로 각각 +1.67/+3px 정렬했다. 짧은 턱받이와 털색 어깨, 앞발을 연결했다. alignment-detail.png는 기본형 실제 렌더러의 홀 확대 캡처다.

상판과 벽의 경계 및 다리 안쪽 외곽선 보강: 테이블 알파 실루엣에 번짐 없는 1 art px 갈색 외곽선을 CSS drop-shadow로 적용. table-outline.png에서 기본 목재형 마감 확인. 기본형/핑크형에 같은 규칙 적용.

외곽선 두께 재조정: 추가 그림자 오프셋을 1→0.25 art px로 줄이고 #493021→#76523e로 완화. 기존 스프라이트 테두리 위에 두꺼운 선이 겹치던 현상 수정. thin-outline.png에서 목재/핑크 두 테마 확인.
