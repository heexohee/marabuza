## A — 밸런스 · 글자 넘침

- **A-01** PASS — 2일차 열 때 옥수수면 10/12 · 창고 20, 새우 꼬지 10/12 · 창고 0(창고 전부). 10에서 보충 → 12/12(칸 상한, +2).
- **A-02** PASS — 응대 안 한 첫 손님이 53.3초 뒤 떠남. 기대값은 케이스의 "약 50초"가 아니라 50 ÷ 0.9 ≈ 55.6초(±5)
  — 케이스 문서가 대기열 인내심 0.9를 반영하지 못함 (케이스 수정 필요, 게임 결함 아님).
- **A-03–A-05** PASS — 게임 봇(보통, 사람 속도 대기 없음)으로 2–10일: 매일 밤 📒 `D-n`(5,4,3,2 → 7,6,5,4)·임대료 194,000·할부 266,800 일치.
  7일차 차감 460,800원(194,000 + 266,800), 남은 권리금 800,200원. 돈 596,800(2일) → 942,600(5일) → 620,200(7일 후) → 1,016,400(10일).
  체감 판정은 사람 몫 — 이 봇은 사람보다 빨라 떠난 손님 0명(참고: 28일 시뮬 등급별 결과는 `shelf-patience-evidence.md`).
- **A-06 / A-07** PASS(레이아웃) — 2–6·8–10일차 사장 대사 모두 두 줄 이하, 넘침 없음, `word-break: keep-all`, 화면 안, 스크롤 없음 (두 창 크기).
  1일차는 저장으로 못 만들어 제외(스모크에서 새 게임으로 확인).
  **FAIL(내용)** — 8·10일차 대사가 사이드 메뉴를 안 넣어도 "음료 한 박스를 보내 주셨어!", "웍이 생겼다!"라고 함 → **BUG-001**.
- **A-08** PASS — 📒 팝업: 두 창 크기 × (충분 / 부족 "일요일까지 340,800원 더 벌어야 해요") 모두 화면 안, 잘린 글자 0,
