## 고정 무대 + 창 맞춤 (2026-09-27, Steam 대비 — 스크롤 금지)

- `#app`을 1280×884 고정 무대로 두고 `--fit = min(창 폭/1280, 창 높이/884)`로 통째 확대·축소 (`src/js/self-serve/fit.js`, 테스트 `tests/unit/self-serve/fit_test.mjs` 4개).
- 폭 기준 `@media`는 `#app` 컨테이너 쿼리로 바꿔 항상 1280 배치가 쓰이게 함 (좁은 배치는 잠든 채 남음). 1.1배 zoom 규칙 삭제.
- 확인: 1280×720 → 0.814배, 1512×860 → 0.846배. 페이지 스크롤 없음, 게임 화면 버튼·클릭 대상 28개 클릭 위치 정상, 콘솔 오류 없음. → `09-fit-1280x720.png`, `11-fit-wide-window.png`
- 개발 바는 무대 밖 왼쪽 아래 DEV 표시로 접힘 (마우스를 올리면 버튼이 열림).
- 남은 것: 상점 화면은 무대보다 길어서(1750px) 무대 **안에서** 스크롤됨 → `10-fit-shop.png`. 한 화면에 맞추려면 탭이나 촘촘한 배치가 필요.
