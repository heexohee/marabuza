## Acceptance criteria

| # | Criterion | Result | How observed |
|---|---|---|---|
| 1 | 가운데 영역 뒤에 마라판다 갈색 노포 실내 배경 | PASS | 01–03: 테이블 패널 뒤 벽지 줄무늬, 패널 사이 나무 벽널, 냄비 패널 뒤 체크 타일 바닥 |
| 2 | 고정 비율 무대 — 폭이 바뀌어도 잘리거나 틀어지지 않음 | PASS | 방 이미지는 `100% auto`(폭에 맞춤, 위 정렬)라 가로로 잘리거나 늘어나지 않음. 방보다 높은 부분은 같은 배율 바닥 타일이 반복 — 생성 시 이음새 픽셀 비교 불일치 0 |
| 3 | 기존 조작(클릭, P·C 키)과 위치 그대로, 배경이 클릭을 가로채지 않음 | PASS | 빈 테이블·냄비·주문표 줄·진열대 칸의 중심 좌표 `elementFromPoint`가 각 요소 자신을 반환. P → 일시정지, P → 해제, C → "대기 중인 주문표가 없어요" |
| 4 | 좁은 화면(≤700px)에서 읽을 수 있고 UI가 겹치지 않음 — 배치 규칙 확정 | PASS (규칙 확정) | 03: 가로 넘침 없음. **규칙**: ≤700px에서는 방이 폭에 맞춰 작아져 벽널 경계선이 테이블 패널을 가로지르므로, 테이블 패널 불투명도를 50% → 78%로 올려 라벨을 깨끗하게 유지 |
| 5 | 배경 이미지가 로드되지 않아도 조작이 막히지 않음 | PASS | 04: 배경을 없는 경로로 바꾸면 기본 바닥색 `rgb(204,130,72)`만 보이고, 진열대 보충 클릭이 정상 동작, 냄비 좌표도 냄비 자신에 닿음 |

## Notes

- 1차 배경(에이전트 작성)은 벽에 냉장고·메뉴판·등롱이 있었으나 반투명 테이블 패널 뒤로 비쳐 "빈 테이블" 칸 위에 메뉴판 글씨가 겹침 → 소품을 빼고 벽지·벽널·타일만 남김(셀프 냉장고는 왼쪽 진열대가 담당).
- 패널 투명도는 72%(방이 거의 안 보임) → 데스크톱 기준 테이블 50% / 냄비 45%로 확정.
- Feel(질감이 "가게 안 같다"는 인상)은 스틸 스크린샷으로 판정하지 않음 — 플레이테스트/리드 확인 대상.
