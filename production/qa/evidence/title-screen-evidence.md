# 타이틀 화면 — 증거 (2026-09-27)

사용자 결정: 시안 1(비 온 밤 골목) · 구도 ② 가게 왼쪽 · 로고는 인게임 간판 스타일로 가게 지붕 위 · 메뉴는 데이브 더 다이브처럼 흰 픽셀 글씨(Galmuri 굵게) · 부제 "퇴사하고 마라탕집 사장님"(가게 간판).

- 배경 `src/img/title-bg.png` (800×442, `tools/art/title_bg.py`): 창 전체를 가로로 꽉 채움(cover). 옆 건물 창은 노랑·파랑, 가로등은 노란 불, 핑크는 가게만. 로고 "마라부자"는 지붕 위 네온 간판으로 그림 안에 그려 넣음(창 크기와 상관없이 가게 위).
- 메뉴: 새 게임 / 이어서 하기(세이브 없으면 꺼짐) / 불러오기(준비 중, 꺼짐) / 설정(게임방법 · 전체화면 · 기존 흐름 링크 · 닫기).
- 조작: 마우스를 올리면 선택, ↑↓로 이동(꺼진 항목은 건너뜀), Enter/Space 실행, Esc로 설정·게임방법 닫기. 세이브가 있으면 "이어서 하기"가 처음 선택됨.
- 확인(1600×749 창): 세이브 없음 → "새 게임" 선택, ↓ 두 번에 설정→새 게임으로 순환, 설정 열기/Esc 닫기, 새 게임 → 오프닝(배경이 게임 배경으로 돌아옴), 세이브 후 새로고침 → "이어서 하기" 선택 → Enter로 상점, 타이틀 버튼으로 복귀. 콘솔 오류 없음.
