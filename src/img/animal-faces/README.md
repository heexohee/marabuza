# 대기열 동물 얼굴

2026-09-28 승인된 정면 시안을 대기열에 반영.

- 원본: `design/animal-face-concepts/front-v2/original-seven-front.png`, `additional-seven-front.png`.
- 14종 각각 48×48 PNG, 가장 긴 변 44px, 아래 여백 2px. 최근접 축소, 알파 128 기준 이진화, 최대 24색 팔레트, 디더링 없음.
- 게임 연결: `src/js/self-serve/animal-faces.js`. 일반 손님 11종 및 단골 너구리 매핑. 참새는 이미지와 매핑을 준비했으며 손님 출현 목록은 기존 설정을 사용.
- 적용 범위: 셀프 담기 대기열 및 착석 손님. 착석 손님은 종별 털색 몸통, 크림색 식사용 턱받이와 앞발을 함께 표시한다. 주문표와 스토리 얼굴은 기존 표현 유지.
- 검증: 이미지 연결/규격 및 스토리 테스트 35개 통과, 릴리스 복사본과 원본 일치, 14개 PNG 알파 0/255 확인. 실제 대기열의 고양이·코알라·토끼 이미지 표시 확인.
- 실행 증거: `production/qa/evidence/animal-queue/queue.png`.

판다 얼굴은 사장 안내 초상화로 사용한다. 판다는 공통 CUSTOMER_FACES에서 제외하여 기본/셀프 담기 모두 일반 손님으로 생성되지 않는다. 얼굴 전용 48×48 이미지를 32×32로 표시하여 전신 이미지의 이마만 잘리던 문제를 수정했다. 판다 매핑은 에셋 호환성을 위해 유지한다.
