# 통합 착석 캐릭터

2026-09-29 승인된 토끼·고양이·곰 시안 반영. 얼굴·어깨·크림색 턱받이·앞발을 한 PNG로 표시한다. 다른 동물과 대기열 얼굴은 기존 방식을 유지.

원본 시안: design/seated-customer-concepts/unified-customers/rabbit-cat-bear-v1.png.
투명 분리 원본: 같은 폴더 sprites-source.png. image_gen에 시안 상단 3종을 동일한 디자인으로 추출하도록 요청. 가구/배경/그릇/그림자 제외, 얼굴부터 앞발까지 연결된 실루엣 유지.

출력: 각 96×112 RGBA PNG, 32색, 디더링 없음, 최근접 축소, 알파 128 기준 이진화. 앞발 하단을 y=110에 맞추고 몸 중심으로 정렬. 게임 표시 크기 40×46.667 art px, 하단 32 art px, 테이블보다 위 레이어로 앞발 표시.

검증: 통합 스프라이트 경로/규격/기존 CSS 몸통 중복 방지 및 착석·서빙 흐름 테스트. 실제 renderer에 테스트 손님 3종과 빈 테이블을 넣어 목재/핑크 가구 확인. applied-wood.png / applied-pink.png는 테스트 상태 캡처이며 사용자 저장 데이터는 수정하지 않았다.

## 고양이 v2 (2026-09-29)
고양이는 사용자 새 레퍼런스를 따라 선명한 레트로 픽셀 화풍으로 교체했다. 호박색 눈·회보라색 윤곽·단순화한 명암. 이번 고양이는 24색, 실루엣82×96, x7/y14 배치. 대기열 얼굴도 같은 디자인으로 교체. 원본/백업/검증: design/seated-customer-concepts/cat-retro-v2/README.md.

## 개성 있는 손님 13종 (2026-09-29 승인)
이후 승인한 personality-01/02 시트로 고양이·토끼를 포함한 13종을 모두 교체했다. 현재 출력은 32색, 앞발 하단 y110, 96×112 규격. 대기열과 주문표는 동일 디자인의 48×48 얼굴 사용. 이미지 버전3, 판다 사장 이미지는 유지. 최신 원본·변환 좌표·검증 기록: design/seated-customer-concepts/gentle-retro-lineup/README.md 및 runtime-sources/.

## 펭귄 머리 크기 조정
펭귄만 원본 턱 위치 y85를 기준으로 머리를 CSS에서 85%로 축소한다. 같은 PNG를 머리/몸통 두 레이어로 잘라 표시하므로 앞치마와 날개 크기는 유지한다. 대기열·주문표의 펭귄 얼굴에도 85% 배율을 적용한다. 접근성 이름은 착석 캐릭터 전체에 한 번만 제공한다.
