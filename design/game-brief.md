# Game Brief: 마라부자

**One-sentence pitch:** 손님이 직접 담아온 그릇을 무게와 옵션으로 정확히 계산하고, 마라탕·샹궈를 맵기와 시간에 맞춰 끓여내며, 진열대와 소스바가 비지 않게 관리하는 현실판 마라탕 가게 사장 시뮬.

## Core loop
- **셀프 담기**: 손님이 진열대에서 재료를 담아 계산대로 온다 (진열대 재고 차감)
- **계산**: 저울 무게 + 고기·꼬치 개수·고수 여부를 보고 가격 확정 → 마라탕/샹궈 · 맵기 · 땅콩소스 주문 받기
- **조리 → 서빙**: 마라탕(육수)/샹궈(볶음) 방식대로 적정 시간 구간에 건져 서빙. 틈틈이 재고 보충
- **하루 정산**: 매출·평판 확인 → 발주·업그레이드 → 다음 날

가격 = 총무게(고기·꼬치류 제외) × 100g당 단가(마라탕 1,800원 / 샹궈 3,000원) + 고기 추가금(소고기 3,000원 / 양고기 4,000원) + 꼬치 1개당 1,000원(새우·고급 어묵·고급 소시지 모두 꼬치 단위) + 고수 1,000원.
고기와 꼬치·새우는 무게 계산에서 빠지고 추가금으로만 계산한다 (이중 계산 아님).
과다 청구 → 컴플레인·평판↓, 과소 청구 → 손해.

## Player goal & fail state — what "working" looks like
- 목표: 판다 사장님께 **권리금 완납** → 엔딩 "이제 네 가게구나". 중간 목표: **인테리어 6단계**로 갈색 노포를 간판에 걸맞은 핑크 "마라부자"로 완성. 하루(영업시간)가 끝나면 한 세션 완료.
- 실패: **주간 임대료**를 두 주 연속 못 내거나 평판이 0이 되면 폐업(게임 오버).

## Story — "최애 한 그릇" (인수 계약서, 2026-09-26 확정)
- **세계**: 사람과 동물이 함께 사는 도시. 무대는 회사 근처 골목의 오래된 단골집 **"마라판다"**(판다 사장님 가게).
- **주인공**: 번아웃 온 회사원. 하루를 버티게 해준 건 퇴근길 마라판다의 마라탕 한 그릇.
- **발단**: 퇴사한 날 가게에 안내문 — "그동안 감사했습니다. 고향으로 내려갑니다. 가게 넘깁니다 — 판다". "이 맛마저 없어지면…" → **그 자리 그대로 인수**. 퇴직금은 권리금 첫 할부, 나머지는 대출·할부.
- **빚 세 가지 = 게임 구조**
  - **임대료(주세)**: 한 주 = 월~토 영업 6일 + 일요일 휴일. 일요일에 한 주 치를 낸다 — 매주의 압박. 한 번은 연체 가능, 두 주 연속이면 폐업.
  - **권리금**: 판다 사장님께 할부 상환("천천히 갚아" — 다정한 채권자). 완납 = 엔딩. 전체 진행도.
  - **인테리어**: 선택 투자. 간판은 인수 첫날 "마라부자"로 바꿨지만 가게 안은 아직 갈색 노포 — 단계마다 핑크로 바뀌고 분위기 효과(평판·인내심·팁·손님 수·신선도)가 오른다. 벽지 → 바닥 → 조명 → 문·포토존 → 의자·식탁 → 주방.
- **조력자**: 판다 사장님이 가끔 손님으로 와서 조언(튜토리얼 역할). 권리금 받으러 오는 날 = 진행 체크.
- **손님·마음**: 지친 동물 손님들(야근 너구리, 시험기간 토끼…)이 곧 예전의 나 — "내가 위로받던 한 그릇을 누군가에게".
- **메커니즘 연결**: 셀프 담기 = "원하는 대로 고르는 자유" / 정확한 계산 = 회사원 시절 꼼꼼함 / 혼자 다 하다 또 번아웃 올 뻔 → **알바 고용이 곧 주인공의 성장**.
- **오프닝 5장**: ① 야근 밤거리(골목에 갈색 "마라판다" 간판) → ② 마라판다 실내, 단골 대화 → ③ 가게 넘김 안내문 + "권리금은 천천히 갚아" → (캐릭터 만들기) → ④ 인수 첫날, 같은 갈색 실내에서 사장님이 건넨 앞치마를 입는다 → ⑤ **간판 교체**(2026-09-26): 갈색 "마라판다" 간판을 내리고, 판다 사장님 "간판은 바꿔도 돼. 맛은 그대로잖아." → 천을 벗기면 핑크 "마라부자" 네온 점등 → **타이틀 드롭**(제목 로고 등장) → 첫 영업. 현실처럼 새 사장은 간판부터 바꾸고, 가게 안을 간판에 맞춰 가는 게 인테리어.
- **엔딩(권리금 완납)**: 판다 사장님 "이제 네 가게구나", 옛 "마라판다" 간판을 가게 안 액자로 건다.
- **톤**: 밝고 따뜻한 일상 힐링. 빚은 압박이지 절망이 아니다.
- **노출 방식**: 오프닝 컷 5장, 하루 시작·마감 1–2줄 대사, 단골 동물 짧은 대사. 금액 체계는 아래 "경제 레벨링".

## 영업 화면 — 가게 단면 (2026-09-26 개정)
- **한 줄**: 영업 화면 가운데가 옆에서 본 마라판다 가게. 손님이 문으로 들어와 자기 식탁에 앉고, 주방에서 끓인 마라탕을 가져다주면 먹고 나간다. 인테리어를 할수록 갈색 노포 → 핑크 "마라부자"로 바뀌고, 하루 동안 창밖이 아침 → 밤으로 흐른다.
- **그대로**: 진열대(왼쪽), 저울·계산대(오른쪽), 주문표 레일 — 조작 방식 유지.
- **가게 단면 (가운데)**: 뒷벽(간판·등롱·메뉴판·창, 준비중/영업중 표시), 왼쪽 문, 식탁·의자(번호 꽂이), 오른쪽 끝 주방(가스불·후드·냄비)이 한 장면. 오프닝과 같은 고정 비율 도트 무대.
- **손님 동선**: 결제한 손님이 문 → 자기 번호 식탁으로 바닥 위를 옆으로 이동해 앉음 → 머리 위 인내심 바 → 음식을 받으면 먹음 → 하트·동전 띄우고 문으로 나감. 인내심이 다하면 화내며 나감.
- **서빙**: 주방 냄비를 집으면 그릇이 따라다니고, 식탁을 누르면 포물선으로 날아가 내려앉음. 먹는 동안 그릇이 비고 김이 오름. 먹는 동안 식탁은 차 있음(식사 시간은 짧게 시작해 플레이테스트로 조정).
- **인테리어 6단계 = 가게를 간판에 맞추는 과정** (2026-09-26 개정, 상점 구매, 순서대로 · 해금일 이후 · 돈이 있으면): 0 갈색 노포(간판만 핑크 "마라부자") → 1 벽지(평판 소폭 ↑, 1일차) → 2 바닥(인내심 소폭 ↑, 3일차) → 3 조명: 등롱 → 핑크 펜던트(식사 후 팁 ↑, 5일차) → 4 문·포토존: 핑크 차양·문, 네온 하트(손님 방문 ↑, 7일차) → 5 의자·식탁: 흰 상판 + 민트 의자(식사 후 평판 상승폭 ↑, 9일차) → 6 주방: 핑크 타일·새 후드·냉장 설비(채소 시듦 느리게, 12일차). 효과는 분위기만 — 테이블 수는 좌석 확장(2 → 최대 4), 조리 속도는 화력이 맡는다. 기존 "인테리어 +15%" 업그레이드는 이것으로 대체. 시안: `design/art/interior-mockups/`.
- **하루 시간대 (120초)**: 오전(준비중→영업중) → 점심 러시(창밖 줄, 손님이 가장 많음) → 오후 노을 → 마감 직전 밤(네온·등롱). 옅은 시간대 색은 단면에만, 조작 영역은 읽기 쉽게.
- **움직임 줄이기**(`prefers-reduced-motion`)면 이동·비행 없이 바로 바뀜.
- **Out of scope**: 길찾기, 사장 캐릭터 이동, 가구 자유 배치, 날씨, 여러 지점, 사운드. (손님이 문으로 들어오고 나가는 이동만 허용)
- **Build order**: ① 가게 단면 배치 → ② 손님 입장·착석·퇴장 → ③ 서빙 비행·식사 → ④ 시간대 → ⑤ 인테리어 1–6단계 → ⑥ 점심 러시 → ⑦ 오프닝 5장 간판 교체 + 타이틀 드롭.

## 경제 레벨링 (2026-09-26)
- **기준 D** = 1주차(식탁 2·냄비 1) 하루 평균 순이익(매출 − 재료비). 시뮬레이션·플레이테스트로 측정하고 모든 가격은 D 배수 — 단가가 바뀌면 D만 다시 잰다.
- **측정값 (2026-09-27)**: `node tools/sim/baseline_day.mjs` — 1주차 하루 40번, 봇(계산 실수 포함) 기준 **D = 97,000원** (실수 없는 봇 97,507원). 가격표 = D 배수, `src/js/self-serve/data.js` `BASELINE_D`·`priceOf` 한 곳:
  - 임대료 194,000원/주 · 권리금 2,910,000원 (주 최소 48,500원)
  - 인테리어 97,000 / 145,500 / 194,000 / 291,000 / 388,000 / 485,000원
  - 좌석 확장 194,000 / 388,000원 · 냄비 145,500 / 291,000 / 582,000원 · 화력 97,000 / 194,000 / 388,000원
- **한 주** = 월~토 영업 6일 + **일요일 휴일**(영업 없음 — 임대료·권리금 납부와 상점만 하는 날).
- **주간 임대료** ≈ 2D, 일요일 납부. 못 내면 **연체**(경고, 다음 주에 두 주 치) — 두 주 연속 못 내면 폐업.
- **권리금** 총 ≈ 30D, 일요일마다 최소 0.5D 할부 + 추가 상환 가능. 완납 = 엔딩 (추가 상환 포함 목표 6–8주).
- **인테리어** 1–6 ≈ 1 / 1.5 / 2 / 3 / 4 / 5D (합 ≈ 16.5D), 해금 1 / 3 / 5 / 7 / 9 / 12일차(영업일 기준).
- **좌석 확장** 2 → 4 (2회 구매) ≈ 2 / 4D. 냄비·화력 업그레이드도 D 배수(1–6D)로 재정렬.
- **메뉴 단가**: 마라탕·샹궈 100g 단가를 상점에서 각각 조정 (기본 1,800 / 3,000원, 추가요금은 고정) — 계산기(저울 영수증·정답 가격)와 손님 수에 그대로 반영. D는 기본 단가로 측정.
- 수치는 `data.js` 한 곳, 플레이테스트로 조정.

## MVP — what must exist to be the game
1. 셀프 진열대: 손님이 직접 담은 그릇 생성, 진열대 재고 차감
2. 계산대: 무게·고기·꼬치·고수로 금액 확정 (틀리면 손해/컴플레인)
3. 주문 옵션: 마라탕/샹궈, 맵기, 땅콩소스
4. 조리 타이밍: 모드별 적정 시간 게이지
5. 하루 정산 + 발주/업그레이드 + 저장 (최소형)
6. *(2차)* 재고 보충: 진열대·소스바 (손님이 소스바 셀프 사용)
7. *(2차)* 사이드: 꿔바로우, 달걀볶음밥, 중국 음료·캔음료
8. *(2차)* 알바 고용 — 보충 담당 1명부터. 스토리상 "혼자 다 하지 않기"라는 성장 (플레이테스트 2026-09-25에서 러시 과부하로 필요성 확인)
9. *(2차)* 스토리 노출 — 오프닝 컷, 하루 시작·마감 대사, 단골 동물 대사

## Out of scope — not building this
- 사운드
- 완전 자동화 (알바가 가게를 대신 운영)
- 여러 지점 운영 · 가게 이전 (인수한 한 자리에서만 성장)
- 멀티플레이·서버 저장

## Build order
1. 계산대 가격 매기기 (핵심 재미 — 가장 먼저 검증)
2. 주문 옵션 + 마라탕/샹궈 조리 타이밍
3. 셀프 담기 손님 생성 + 진열대 재고
4. 하루 정산·발주·저장 → **여기서 플레이테스트**
5. 소스바·재고 보충
6. 사이드 메뉴
7. 그래픽 다듬기

**Who it's for / what they feel:** 마라탕 좀 먹어본 사람들이 "진짜 가게 이렇지" 하는 현실 고증 손맛과 점심 러시의 바쁜 계산대 긴장감.

**Art & audio direction:** '때부자' 풍 파스텔 픽셀 아트 — 동글동글 동물 손님, 굵은 테두리 슬롯 UI. 간판은 오프닝 끝에 핑크 "마라부자"로 바뀌고, 가게 안이 **갈색 노포 → 핑크 파스텔** 로 변신하는 것이 시각적 진행도. 영업 화면도 오프닝과 같은 도트 무대를 쓰고, 인테리어 단계와 시간대가 그 무대 위에서 보인다.
