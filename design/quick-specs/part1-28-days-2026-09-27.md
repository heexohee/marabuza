# Quick Design Spec: 1부 "28일" — 날짜별 스토리 · 권리금 4주 분할 · 엔딩 · 2부 예고

**Type**: Narrative + Economy rule change (1부 완결 구조)
**Scope**: 1–28일차를 한 편의 이야기(1부)로 완결한다. 권리금을 4주에 나눠 갚고, 28일차 일요일에 엔딩, 29일차부터 2부 예고.
**설계 기준**: `design/game-brief.md` Story "최애 한 그릇", 경제 레벨링 · `design/quick-specs/story-character-2026-09-25.md`(인물·연출)
**Date**: 2026-09-27
**Status**: Approved (2026-09-27)

## 결정 (2026-09-27, 사용자)
- 1부 = **28일 고정**. 28일차(4주차 일요일)에 엔딩.
- 권리금 = **4주 분할 필수 납부** (일요일 7·14·21·28일차, 매주 1/4).
- 28일차에 다 못 갚았으면 **판다 사장님이 탕감** — 엔딩 흐름은 같고 대사·보상만 다름.
- 주차 흐름: 1주 적응 → 2주 단골과 새 메뉴 → 3주 번아웃 위기("혼자 다 하지 않기") → 4주 판다 사장님 방문 준비 → 28일차 엔딩 + 2부 예고.

## A. 권리금 4주 분할 (기존 "최소 0.5D 할부 + 추가 상환, 6–8주 목표"를 대체)

1. 권리금 총액 `P`, 주 할부 `P / 4`. 일요일 장부 순서: ① 이번 주 매출 ② 임대료 −2D ③ **권리금 할부** −(P/4 + 밀린 할부) ④ 남은 돈 + 남은 권리금 막대 → 더 갚기(+1만 / +5만 / 가능한 만큼) → 상점.
2. 돈이 모자라 할부를 다 못 내면: 낼 수 있는 만큼만 빠지고, 나머지는 **다음 주로 이월**(권리금 줄에 연체 도장 + 판다 사장님 "괜찮아, 다음 주에 같이 줘"). **권리금 때문에는 폐업하지 않는다** — 폐업은 임대료 규칙(두 주 연속 미납)만.
3. 더 갚기로 일찍 다 갚아도 엔딩은 28일차. 다 갚은 뒤 일요일 권리금 줄은 "완납 ✓" + 판다 "벌써? 28일에 보자."
4. 28일차 장부 뒤 → 엔딩 컷씬. 남은 권리금 > 0이면 탕감 대사로 0이 된다.
5. 29일차부터: 권리금 줄 없음, 임대료만. (2부 콘텐츠 전까지는 같은 루프로 계속 영업)

**`P` 시작값 제안 = 8D (776,000원, 주 194,000원 = 2D).** 한 주 순이익 ≈ 6D − 임대료 2D = 4D 가운데 2D가 권리금, 남는 2D로 인테리어·설비 — "갚으면서 조금씩 꾸미는" 속도. 최종값은 밸런스 단계(아래 E)에서 봇 시뮬레이션으로 확정.

## C. 28일차 엔딩 컷씬

일요일 장부(4회차) 다음, 오프닝과 같은 장면 연출(`OPENING_SCENES` 방식, 배경 `scene-ending` = 일요일 저녁 가게 안).

**완납했을 때**
1. 자막: "28일차, 일요일 저녁."
2. (판다 사장님 등장) 🐼 "장부 봤어. …다 갚았네."
3. 🙂 "사장님 덕분이에요."
4. 🐼 "아니. 이제 네 가게구나."
5. 🐼 "이건 가져가려다 말았어. 여기 두는 게 맞겠다." → 옛 **"마라판다" 간판이 벽에 액자로** 걸린다 (배경 전환). 액자 아래 금색 **"완납"** 명패.
6. 🙂 "{name} 사장의 마라부자. 내일도 한 그릇씩!"
7. 자막: "마라부자 1부 — 끝"

**다 못 갚았을 때** (2~4만 다름)
2. 🐼 "장부 봤어. 조금 남았네."
3. 🙂 "죄송해요… 조금만 더 시간을 주시면—"
4. 🐼 "됐어. 나머지는 그동안 손님들한테 내준 한 그릇으로 받았다 치자. …이제 네 가게구나."
5. 같은 액자, 명패 없음. 남은 권리금 0으로.

엔딩 뒤: 상점 → 29일차. 단면 벽에 액자가 계속 보인다. `endingSeen`·`premiumPaidInFull` 저장.

## D. 2부 예고 (29일차 아침, 엔딩 다음 영업 시작 전 짧은 장면)

1. 자막: "29일차, 월요일 아침."
2. **떡밥 (결정 2026-09-27: 알바 + 프랜차이즈)**
   - 🐰 토끼가 문에 붙은 "알바 구함" 전단을 들고 온다: "사장님, 저 여기서 일해도 돼요?" — 3주차 "혼자 다 하지 않기"의 답. **2부 첫 목표 = 알바**(브리프 MVP 8).
   - 🙂 문밖을 보니 맞은편 건물에 대형 프랜차이즈 마라탕 **"오픈 예정"** 현수막. 🙂 "…저기도 마라탕?" — **2부 전체 갈등 = 경쟁 가게**.
   - (검토에서 뺀 안: 건물주 임대료 인상)
3. 자막: "마라부자 2부 — 준비 중". 2부 콘텐츠가 생기기 전까지는 같은 루프로 계속 영업.

## E. 밸런스 목표 (4단계에서 확인)

`tools/sim/` 봇(계산 실수 포함)으로 28일을 돌려서:
- 보통 봇: 권리금 4회 모두 제때 납부 + 인테리어 3단계 이상, 임대료 연체 0회
- 서툰 봇(실수 많음): 권리금 일부 이월, 28일차 탕감 엔딩, 폐업은 없음
- 잘하는 봇: 3주차 안에 완납 가능
위를 만족하도록 `P`(권리금 총액)와 필요하면 인테리어 가격을 조정.

**결과 (B001, 2026-09-27)** — `tools/sim/part1_run.mjs`, 봇에 사람 속도(조작 사이 1.1–2초)를 넣고 3단계 × 8시드:
- 확정값: **P = 10D (970,000원)**, 시작 자본금 **500,000원**, 손님 증가 **0.1초/일**(기존 0.4). 인테리어 가격은 그대로.
- P = 8이면 서툰 봇도 대부분 완납(탕감 1/6) → 10으로. 손님 증가 0.4에선 모든 봇이 3주차부터 손님을 놓쳐 평판 0 → 0.1로.
- 보통: 8/8 제때 납부 · 인테리어 평균 3.8 · 연체 0 · 서툰: 탕감 6/8 · 폐업 0 · 잘하는(갚기 우선): 21일차 완납 8/8

## Acceptance Criteria
- [ ] 일요일(7·14·21·28)마다 권리금 P/4(+이월분)이 임대료 다음에 빠지고, 모자라면 이월 + 연체 도장, 권리금으로는 폐업하지 않는다
- [ ] 더 갚기로 일찍 완납할 수 있고, 엔딩은 28일차에만 나온다
- [ ] 4–28일차 아침 한마디가 표대로 날짜마다 다르게 나온다 (1–3일차 기존 팁 유지)
- [ ] 표의 날짜에 단골(너구리·토끼·곰)이 손님으로 와서 계산대에서 한마디 한다
- [ ] 28일차 장부 뒤 엔딩 컷씬이 완납 / 탕감 두 갈래로 나오고, 액자가 단면 벽에 남는다
- [ ] 29일차 시작 전 2부 예고 장면이 한 번 나온다
- [ ] 남은 권리금·이월분·엔딩·예고 본 여부가 저장·로드된다
- [ ] 봇 시뮬레이션이 E의 목표를 만족한다
