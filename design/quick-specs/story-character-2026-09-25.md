# Quick Design Spec: 주인공 캐릭터 + 스토리 연출 (셀프 담기)

**Type**: New Small System
**Scope**: 셀프 담기 버전(`src/self-serve.html`)에만. 여자 주인공 픽셀 캐릭터 생성(꾸미기), 오프닝 컷씬 4장, 하루 시작·마감 한마디, 계산대에 주인공 표시. 기존 흐름(사장이 담기)은 비교용으로 그대로.
**설계 기준**: `design/game-brief.md` Story "최애 한 그릇"
**Date**: 2026-09-25

## Core Rules

### A. 주인공 만들기
1. 게임하기 → 캐릭터 만들기 화면. 이어하기는 저장된 주인공으로 바로 상점.
2. 고르는 것: 참고 이미지 1·2·3번 캐릭터를 기본형으로, 머리 기장 3 (단발 / 긴 머리 / 포니테일), 머리색 3 (갈색·흑발·금발), 앞치마 색 3 (분홍·민트·노랑). 기본값은 1번(단발·갈색·분홍). 없어진 색이 든 옛 세이브는 기본값으로 돌린다. 그리고 이름(1–8자, 공백만이면 기본 이름).
3. 주인공은 64×112 픽셀 스프라이트로, **공통 몸 1장 + 머리 모양별 머리 층**을 겹쳐 만든다. 공통 몸은 참고 이미지 1번(단발)의 얼굴·신체에 2번(긴 머리)의 셔츠·앞치마를 합친 것이다. 머리 층은 목(`HERO_NECK_Y`)까지는 몸 위(앞머리가 얼굴을 덮음), 그 아래는 몸 뒤(옆머리·포니테일)에 그린다. 꾸미기는 머리 층을 갈아끼우고 색만 바꾼다. 데이터는 `tools/art/hero_sprites.py`가 참고 이미지 `assets/art/hero-reference.webp`를 박스 축소해 `src/js/self-serve/hero-art.js`로 만든다. 머리는 7단계(`0`–`6`), 앞치마는 5단계(`V`–`Z`) 명암 칸이다. 고른 색의 [밝은·기본·어두운] 3색으로 단계별 색을 만들어 칠하므로, 원본의 명암·광택이 어떤 색에서도 유지된다. 나머지(피부·셔츠·치마·신발·눈·윤곽선)는 공통 고정색이다. 게임은 외부 이미지 없이 이 데이터로 canvas에 그린다.
4. 주인공 외형·이름은 저장된다. 이전 세이브(주인공 없음)는 기본 주인공으로 불러온다.

### B. 오프닝 컷씬 (4장)
1. 야근 사무실(새벽 2시) → 2. 퇴근길 단골집, 판다 사장님 → 3. 퇴사한 날 "폐업 안내" → 4. 동물 마을 골목, 가게 오픈.
2. 장면 = 픽셀 배경 + 소품 스프라이트 + 등장인물. 대사 상자에 한 줄씩, 클릭(또는 Space/Enter)으로 넘김. "건너뛰기"로 바로 1일차.
3. 대사의 `{name}`은 주인공 이름으로 바뀐다. 화자 "나"는 주인공 이름으로 표시.

### C. 하루 한마디
1. 영업 시작: 계산대 위 주인공 말풍선으로 한 줄(`DAY_LINE_SEC` 동안). 1–3일차는 판다 사장님의 요령 조언, 이후엔 돌아가며.
2. 마감: 정산 화면 맨 위에 그날 결과에 맞는 한 줄 (계산 완벽 / 폐기 있음 / 손님 이탈 / 기본).

### D. 계산대 표시
계산대 패널 위에 주인공 스프라이트와 "사장 {name}" 표시.

## Tuning Knobs
| Knob | Default | Range | Category | Rationale |
|---|---|---|---|---|
| `NAME_MAX_LEN` | 8 | 4–12 | gate | 좁은 계산대 패널에 들어가는 길이 |
| `DAY_LINE_SEC` | 5 | 3–8 | feel | 영업 시작 한마디 표시 시간 |

## Acceptance Criteria
- [ ] 게임하기 → 캐릭터 만들기 → 오프닝 4장 → 1일차 순서로 진행되고, 건너뛰기로 바로 1일차
- [ ] 꾸미기 선택이 미리보기 스프라이트에 즉시 반영되고, 잘못된 값은 무시
- [ ] 이름은 1–8자, 공백만이면 기본 이름
- [ ] 오프닝 대사에 이름이 들어가고, 화자 "나"가 이름으로 표시
- [ ] 영업 시작 한마디가 계산대 주인공 말풍선으로 뜨고 사라짐, 마감 한마디가 정산 화면에 표시
- [ ] 주인공이 저장·로드되고, 주인공 없는 이전 세이브도 불러옴
- [ ] 회귀: 영업·계산·보충 로직 테스트 전부 통과

## Out of scope (now)
단골 동물별 대사, 대출 상환 진행도, 엔딩, 표정·애니메이션, 옷·소품 추가 꾸미기.
